# คู่มือการใช้งานระบบ PR-OS (User Training Guide & Cheat Sheet)
**ระบบบริหารจัดการงานประชาสัมพันธ์ เทศบาลนครนครสวรรค์**

---

## 📌 บทนำและภาพรวมระบบ
PR-OS ออกแบบมาเพื่อรวมศูนย์การบริหารงานประชาสัมพันธ์ของเทศบาลนครนครสวรรค์ จากเดิมที่กระจายตัวตามกลุ่ม LINE หรือกระดานไวท์บอร์ด ให้มาอยู่ในระบบเดียวที่มองเห็นภาพรวม ตรวจสอบได้ และส่งต่อข้อมูลถึงผู้ปฏิบัติงานได้ทันที

---

## 👤 คู่มือตามบทบาทการทำงาน

### 1. ผู้รับมอบหมายงาน / ช่างภาพ / พิธีกร (Assignee)
**เข้าใช้งานผ่าน**: สมาร์ทโฟนหรือคอมพิวเตอร์ 👉 **`/mobile/my-tasks`**

#### ขั้นตอนการทำงาน:
1. **เข้าสู่ระบบ**: ล็อกอินด้วย Username และ Password ของตนเอง
2. **ดูงานที่ได้รับมอบหมาย**:
   - ระบบจะแสดงรายการงานทั้งหมดที่คุณได้รับมอบหมาย เรียงตามวันและเวลา
   - มีข้อมูลครบถ้วน: ชื่องาน, วันที่, เวลาเริ่ม-สิ้นสุด, สถานที่, และหมายเหตุ
3. **กดยืนยันรับทราบงาน**:
   - กดปุ่มสีเขียว **"รับทราบงาน"** เพื่อยืนยันว่าเห็นและเตรียมตัวสำหรับงานนี้แล้ว
   - หัวหน้างานจะเห็นสถานะรับทราบทันทีบนหน้าจอหลัก
4. **หากงานมีการเปลี่ยนแปลง**:
   - เมื่องานมีการเลื่อนเวลาหรือเปลี่ยนสถานที่ แถบสถานะจะขึ้นสีส้มว่า **"มีการเปลี่ยนแปลง"**
   - ให้ตรวจสอบข้อมูลใหม่แล้วกด **"รับทราบงาน"** อีกครั้ง

### 2. เจ้าหน้าที่บันทึกงาน (Staff)
**เข้าใช้งานผ่าน**: คอมพิวเตอร์ 👉 **`/events/new`** และ **`/schedule`**

#### 2.1 การเพิ่มงานใหม่ (`/events/new`):
1. กรอก **ชื่องาน**, **วันที่**, **เวลาเริ่ม** (จำเป็น)
2. เลือก **สถานที่** (เช่น ห้องประชุมสภาฯ, พาสาน, อุทยานสวรรค์ ฯลฯ)
3. เลือก **สำนัก/กอง เจ้าของเรื่อง** และ **ประเภทงาน**
4. เลือก **ผู้ปฏิบัติงาน** และ **บทบาท** (เช่น ช่างภาพนิ่ง, พิธีกร, ถ่ายทอดสด)
5. กรอก **หมายเหตุบนจอมอนิเตอร์** (ข้อความสั้น) และ **หมายเหตุภายใน** (ถ้ามี)
6. กด **"บันทึกร่าง"** หรือ **"เผยแพร่"**

#### 2.2 การใช้ปุ่ม "คัดลอกงาน" (Duplicate Event):
- สำหรับงานประชุมประจำหรืองานที่มีรูปแบบเดิม:
  - เปิดหน้ารายละเอียดงานเดิม (`/events/[id]`)
  - กดปุ่ม **"คัดลอกงาน"** ในแถบการดำเนินการ
  - ระบบจะนำข้อมูลเดิมทั้งหมดมาใส่ในฟอร์มสร้างงานใหม่อัตโนมัติ ให้คุณแก้ไขเฉพาะวันที่/เวลาแล้วบันทึกได้ทันที

#### 2.3 การตรวจสอบเวลาชนกัน (Conflict Warning):
- หากมอบหมายงานให้เจ้าหน้าที่ที่ติดงานอื่นในวันเดียวกัน ระบบจะแสดงแถบเตือนสีส้มทันที:
  `⚠️ เวลาอาจชนกัน: มีงานอื่นในวันเดียวกัน — [ชื่องาน] ([เวลา]) ที่ [สถานที่]`
- ช่วยให้หัวหน้างานปรับเปลี่ยนผู้รับผิดชอบได้ทันท่วงทีก่อนเกิดปัญหา

#### 2.4 การแนบไฟล์ส่วนตัว:
- ในหน้ารายละเอียดงาน สามารถแนบไฟล์กำหนดการ, หนังสือราชการ (PDF/Word/Excel/รูปภาพ) ได้สูงสุด 10 MB ต่อไฟล์ โดยไฟล์จะถูกเก็บเป็นความลับและเปิดได้เฉพาะผู้มีสิทธิ์เท่านั้น

### 3. หัวหน้างานและผู้บริหาร (Supervisor / Admin)
**เข้าใช้งานผ่าน**: คอมพิวเตอร์หรือแท็บเล็ต 👉 **`/schedule`** และ **`/reports`**

#### 3.1 การตรวจสอบตารางงานและปฏิทิน (`/schedule`):
- **สลับมุมมองได้ 3 รูปแบบ**:
  - 📋 **ตาราง (Table)**: ดูรายชื่องานแบบกระชับ พร้อมตัวกรองตามสำนัก/กอง และสถานะ
  - 📅 **รายเดือน (Month)**: ปฏิทินรายเดือนภาษาไทย แสดงความหนาแน่นของงานในแต่ละวัน
  - 🗓️ **รายสัปดาห์ (Week)**: ไทม์ไลน์ 7 วัน แสดงการจัดสรรคิวงานและช่างภาพ
- **การอนุมัติงาน**:
  - กดเข้าไปที่งานสถานะ "ร่าง" เพื่อตรวจสอบความถูกต้อง แล้วกดปุ่ม **"เผยแพร่"** (งานจะขึ้นบนจอมอนิเตอร์และส่งแจ้งเตือนทันที)
  - เมื่องานเสร็จสิ้น กดปุ่ม **"ปิดงาน (เสร็จสิ้น)"**

#### 3.2 การดูรายงานและส่งออกข้อมูล (`/reports`):
1. เลือกช่วงวันที่ที่ต้องการสรุป (เช่น ต้นเดือนถึงสิ้นเดือน)
2. ดู **Smart Summary** สรุปภาพรวมงาน, ภาระงานแยกตามบุคคล, และงานที่ยังค้างรับทราบ
3. **ส่งออกรายงาน**:
   - กดปุ่ม **"ดาวน์โหลด Excel"** ➜ ได้ไฟล์ `.xlsx` สรุปยอดและแจกแจงภาระงาน
   - กดปุ่ม **"พิมพ์ / บันทึก PDF"** ➜ เปิดหน้ากระดาษจัดพิมพ์สำหรับเสนอผู้บริหาร

### 4. การตั้งค่าจอมอนิเตอร์ในห้องทำงาน (TV Display Setup)
**เปิดผ่าน**: Smart TV หรือคอมพิวเตอร์ที่ต่อจอมอนิเตอร์ในห้องประชาสัมพันธ์ 👉 **`/monitor`**

#### ขั้นตอนการเปิด:
1. เปิด Web Browser บน Smart TV หรือกล่อง Android Box
2. พิมพ์ URL: `http://[IP-หรือ-Domain]:3001/monitor`
3. กดปุ่ม **F11** หรือตั้งค่าให้เบราว์เซอร์แสดงผล **เต็มจอ (Full Screen)**
4. หน้าจอจะรีเฟรชข้อมูลอัตโนมัติทุกๆ 60 วินาที โดยไม่แสดงข้อมูลส่วนบุคคลหรือเบอร์โทรศัพท์

## 📞 ปัญหาที่พบบ่อย (FAQ)

* **Q: ลืมรหัสผ่านทำอย่างไร?**
  - **A**: แจ้งผู้ดูแลระบบ (Admin) เพื่อรีเซ็ตรหัสผ่านหรือกำหนดรหัสผ่านใหม่ได้ทันทีในหน้า `/settings`
* **Q: ถ้างานถูกยกเลิกกะทันหันต้องทำอย่างไร?**
  - **A**: หัวหน้างานสามารถเข้าไปที่หน้ารายละเอียดงาน แล้วกดปุ่ม **"ยกเลิกงาน"** พร้อมระบุเหตุผล ระบบจะส่งแจ้งเตือนและยกเลิกคิวเตือนล่วงหน้าให้อัตโนมัติ
* **Q: จอมอนิเตอร์ไม่ยอมอัปเดตงานใหม่?**
  - **A**: ตรวจสอบว่างานนั้นถูกกด **"เผยแพร่"** แล้วหรือไม่ (งานสถานะร่างจะไม่แสดงบนจอ) และตรวจการเชื่อมต่ออินเทอร์เน็ตของทีวี
