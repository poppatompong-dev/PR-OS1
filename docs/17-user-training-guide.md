## 2. เริ่มใช้ครั้งแรก (ทำครั้งเดียว ~3 นาที)

1. ในกลุ่ม LINE พิมพ์ **ลงทะเบียน** → กดปุ่ม "ลงทะเบียนรับแจ้งงาน"
2. กด **เพิ่มเพื่อน** บอท "ผู้ช่วยงาน ปชส."
3. รอแอดมินยืนยันชื่อ → บอทส่ง **ลิงก์ Telegram ส่วนตัว** ให้ในแชท LINE (ใช้ได้ 7 วัน)
4. ลงแอป Telegram → กดลิงก์ → กด **Start**
5. บอทเปิด **ทัวร์ 4 หน้า** ให้ดู กด "ต่อไป ▶" จนจบ

ลิงก์หมดอายุ / หาย → ในแชท LINE กับบอท พิมพ์ **ผูก Telegram** ได้ลิงก์ใหม่ทันที

## 4. ทำเองได้ใน Telegram

| พิมพ์ / กด | ได้อะไร |
|---|---|
| ปุ่ม **งาน** (ซ้ายล่าง) / **📋 รายการงาน** | รายการงานทั้งหมด แยกวัน สีบอกสถานะ (เขียว = ส่งทีมแล้ว · เส้นประ = ร่าง · ส้ม = เลื่อน · แดง = ยกเลิก) · แตะงาน → ✏️ แก้ไข / 📢 เผยแพร่ / ⏸️ เลื่อนออกไปก่อน / ✖️ ยกเลิก / 🗑 ลบร่าง · ＋ เพิ่มงาน |
| ＋ **เพิ่มงาน** | ฟอร์ม: ชื่อ วัน เวลา สถานที่ คน+หน้าที่ ไอคอนงาน แนบรูป → บันทึกร่าง หรือ เผยแพร่ |
| **งานของฉัน** | งาน 7 วันข้างหน้า พร้อมปุ่มรับทราบ |
| **ทีมวันนี้ / ทีมพรุ่งนี้** | ใครไปงานไหน |
| **ใครยังไม่รับทราบ** | รายชื่อคนค้าง |
| แก้งานที่ส่งแล้ว | แก้วัน/เวลา/สถานที่/หน้าที่ → ทีมได้การ์ดสีส้ม กดรับทราบใหม่ · เพิ่มคน → การ์ดงานใหม่ · เอาชื่อออก → แจ้ง "ถอนชื่อ" · ใส่เหตุผลได้ |
| `ประกาศ ข้อความ` | ขึ้นแถบวิ่งบนจอทีวี ถึงเที่ยงคืน (ไม่ต้องอนุมัติ) |
| **รูปของฉัน** | ดูการ์ตูนของตัวเอง · ใช้รูปนี้ / ไม่ใช้ (โชว์ชื่อแทน) / ส่งรูปจริงให้วาดใหม่ |
| **ทัวร์** | ดูวิธีใช้ทีละเรื่องอีกครั้ง |
| **ภารกิจ** | ช่วงทดลอง: เช็กลิสต์ 4 ข้อที่ควรลอง (บอทติ๊กให้เอง) |
| **วิธีใช้** | สรุปคำสั่งทั้งหมด |

**ชื่องานยาว** → ในฟอร์มมีช่อง "ชื่อสั้นบนจอ" · **ไอคอนงาน** ระบบเลือกจากชื่องานให้ (🚴 จักรยาน 🪷 ลอยกระทง 🚣 แข่งเรือ 🎤 ประชุม …) เปลี่ยนเองได้

## 5. จอทีวี (ดูอย่างเดียว)

- หัวจอข้างนาฬิกา: 📸 งานที่ออกเดือนนี้ (คน-ครั้ง) · ⭕ รับทราบภายใน 7 วันกี่ % และเฉลี่ยกี่นาที + ⚡ รูปคนที่รับทราบเร็วสุด (ชมทีม · คนที่เลือก "ไม่ใช้รูป" จะไม่ขึ้น · ไม่นับงานทดสอบ)
- ซ้าย: ตัวเลขสรุป · การ์ดงานวันนี้ (หน้าตาคน + หน้าที่) · ช่อง **หมายเหตุบนจอทีวี** ในฟอร์มขึ้นเป็นบรรทัด 📝 ใต้สถานที่ (การ์ดวันนี้ และงานล่วงหน้าที่มีงานเดียวในวันนั้น)
- งานล่วงหน้าดึงได้ถึง 60 วัน (ขวา = 4 วันถัดไปที่มีงาน)
- หน้าที่: พิธีกร · ภาพนิ่ง · ภาพวิดีโอ · ถ่ายทอดสด · ทำข่าว / ข้อมูล · ประสานงาน · ยานพาหนะ / พลขับ · อื่นๆ (ตัดคำว่า "ช่าง" และแยกวิดีโอ/ถ่ายทอดสด 3 พ.ย. 2569 — งานเดิมที่เลือกแบบรวมได้ทั้งสองหน้าที่)
- ขวา: งานล่วงหน้า 4 วันที่มีงาน · ล่าง: อีก 6 วันถัดไป
- แถบวิ่งล่างสุด: ประกาศของทีม + งานยกเลิก/เปลี่ยน → ต่อด้วย 🥇 ราคาทองคำแท่ง (สมาคมค้าทองคำ) · ⛽ น้ำมันวันนี้ (บางจาก) · 📰 พาดหัว Thai PBS เฉพาะเศรษฐกิจ/สังคม/ต่างประเทศ (กรองการเมือง อาชญากรรม ความรุนแรงออก) อัปเดตทุก ~30 นาที
- งานวันนี้ที่**จบแล้วยังอยู่บนจอทั้งวัน** — จางลง มีป้าย "✓ จบแล้ว" อยู่ท้ายรายการ · ขึ้นวันใหม่หายเอง (คุณกุ๊กขอ 3 พ.ย. 2569)
- รูปประจำตัวบนจอ = ชุดที่ทีมทำเอง (3 พ.ย. 2569) · ใครไม่อยากใช้รูป → Telegram พิมพ์ **รูปของฉัน** → 🚫 ไม่ใช้รูป
- 🧑‍🤝‍🧑 **ม้านั่งทีม** (ขึ้นในช่องว่างฝั่งขวาเมื่องานล่วงหน้าไม่ครบ 4 วัน): รูปทุกคน (ไม่รวมแอดมิน) · 📸 = วันนี้ออกงาน · เหรียญประจำเดือน 🏅 ขยันออกงาน 5/10/15 งาน (ทองแดง/เงิน/ทอง) · ⚡ ไวทันใจ (รับทราบทุกงานใน 30 นาที อย่างน้อย 2 งาน) · 🤝 เพื่อนช่วยเพื่อน (รับงานแทนคนที่ไม่สะดวก) · ✍️ ลงงานเอง (ไม่นับหัวหน้า/แอดมิน) · วันที่ 1–7 โชว์เหรียญเดือนก่อน · ได้เหรียญใหม่บอทบอกเจ้าตัวทาง Telegram (≤1 ข้อความ/สัปดาห์, 08:00–21:00) · รูปเด้งทีละคนทุก ~20 วิ
- 🔄 จอทีวีรีเฟรชเองเมื่อมีการอัปเดตระบบ (เช็กทุก 3 นาที) และทุกวัน 05:30

## 6. แอดมิน (เว็บ → ตั้งค่าระบบ → ทีมงาน)

| งาน | ทำที่ไหน |
|---|---|
| ยืนยันชื่อคนลงทะเบียนจากกลุ่ม | กล่อง "LINE ที่ลงทะเบียนจากกลุ่ม" → เลือกชื่อ → ยืนยัน (บอทส่งลิงก์ Telegram ให้เอง) |
| ส่งลิงก์ Telegram ให้คนที่ยังไม่ย้าย | ปุ่ม ✈️ **ส่งลิงก์ Telegram** (วันละครั้งต่อคน · ใช้โควต้า LINE คนละ 1) |
| ส่งข้อความถึงทุกคนใน Telegram | 📣 **ส่งถึงทีมทาง Telegram** (ฟรี · ไม่ส่ง 21:00–07:00) |
| ถามไถ่ทีม (มีปุ่มตอบ) | 📣 กล่องเดียวกัน → ติ๊ก **💬 แนบปุ่มถามไถ่** · ทีมกด 😊 ใช้ได้ดี / 😕 ยังงงอยู่ / 💬 อยากบอกอะไร · 😕 และข้อความ 💬 เด้งถึงแอดมินทาง Telegram · คนละ 1 คำตอบต่อข้อความ · กติกา: สัปดาห์ละไม่เกิน 1 ครั้ง จ–ศ 09:00–16:00 |

### โควต้า LINE (ฟรี 300/เดือน)
- **ไม่นับ:** ทุกอย่างใน Telegram · การตอบกลับเมื่อมีคนพิมพ์ถามบอท LINE
- **นับ:** ข้อความที่บอท LINE ส่งเองถึงคนที่ยังไม่ย้าย (การ์ดงาน เตือน สรุปเช้า ลิงก์ Telegram) — ยิ่งย้ายครบ ยิ่งใกล้ 0

## 8. คำถามที่พบบ่อย

* **ลิงก์ Telegram หมดอายุ / กดแล้วขึ้น "ใช้ไม่ได้"** → แชท LINE กับบอท พิมพ์ **ผูก Telegram** ได้ลิงก์ใหม่
* **ได้งานซ้ำทั้ง LINE และ Telegram?** → ไม่ควรเกิด ผูก Telegram แล้วงานไป Telegram ที่เดียว ถ้าเจอแจ้งแอดมิน
* **ลืมรหัสผ่านเว็บ** → แจ้งแอดมิน รีเซ็ตได้ที่ ตั้งค่าระบบ → ทีมงาน
* **แก้งานที่สั่งไปแล้ว** → Telegram ปุ่ม "งาน" ซ้ายล่าง (LINE พิมพ์ "รายการงาน") → แตะงาน → ✏️ แก้ไข · คนที่ไม่มีบัญชีเว็บแก้ได้เฉพาะงานที่ตัวเองสั่ง
* **งานถูกยกเลิกกะทันหัน** → รายการงาน → แตะงาน → ✖️ ยกเลิกงาน พร้อมเหตุผล ระบบแจ้งทุกคนในงานและยกเลิกการเตือนให้เอง
* **จอทีวีไม่ขึ้นงานใหม่** → งานต้องกด **เผยแพร่** แล้ว (ร่างไม่ขึ้นจอ) จอรีเฟรชเองทุก 1 นาที
